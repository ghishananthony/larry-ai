# Larry Ai

Build Larry as a B2B SaaS platform for college and university libraries. Larry is an AI-powered research assistant that libraries can integrate into their existing library website as a small chat widget or web add-on. Each college gets its own Larry instance, which is connected to that institution's library catalog, database directory, and licensed academic resources. When a student opens Larry, they can enter their own research goal and requirements. Larry analyzes those requirements, identifies the most appropriate resources available through that specific college's library, and eventually searches those databases to help the student locate relevant books, journal articles, and other academic sources. For example, if a student at College A is writing a psychology paper about social media and teenage self-esteem, Larry should examine College A's available databases, determine that resources such as JSTOR or a psychology-focused database may be relevant, and help the student access potential sources through the college's existing subscriptions. Larry should be designed so each institution's resources, subscriptions, authentication, library catalog, and database links can be configured separately. Larry does not provide access to resources the institution does not subscribe to. Larry also must not write students' papers, create research questions or goals, suggest research directions, summarize or explain source contents, or make academic conclusions. The student remains responsible for reading, evaluating, and selecting their sources. Larry's core value proposition is: 'You choose what to research. Larry finds where to look.' The platform should be designed to eventually support many colleges and universities, with each institution having its own securely configured library resources and administrative dashboard. I want my value proposition to be "Find resources faster, with Larry"
